# MindfulYouth-Chatbot-
MindfulYouth – AI-Powered Mental Wellness Companion  A modern, interactive Streamlit-based mental wellness assistant designed for youth. MindfulYouth provides empathetic chat support, mood tracking, wellness tips, and resource guidance, all with a beautifully designed UI.


#🌟 Features
💬 1. AI-Powered Supportive Chatbot
Empathetic, culturally sensitive mental-health guidance
Crisis keyword detection with emergency responses
Smart fallback responses when AI is unavailable 
chatbot
Clean and human-like conversational experience

🎭 2. Mood Tracker
Log daily moods with emojis
Add notes & journal feelings
Mood trend analytics
Wellbeing score calculation (0–100) based on recent mood patterns 
utils
Auto-suggestions for activities based on emotion

📚 3. Mental Health Resources
Helplines
Self-help techniques
External links for professional support
Clean card-based UI for quick reading 
config

✨ 4. Daily Wellness Tips
Automatically rotates wellness tips
Categories like mindfulness, physical health, social wellness, mental improvement 
utils

🎨 5. Modern UI/UX
Custom CSS theme with animations, gradients & responsive design 
styles
Clean layout, polished chat bubbles, styled buttons, and sidebar navigation
Mobile-friendly interface

#🗂️ Project Structure
MindfulYouth/
│── app.py                # Main Streamlit application UI & routing
│── chatbot.py            # AI logic, fallback system, crisis handling
│── config.py             # App configs, theme, AI model, helplines
│── styles.py             # Full CSS and HTML components for UI
│── utils.py              # Mood analytics, wellbeing score, tips, validation
│── .env                  # Environment variables (API keys)
